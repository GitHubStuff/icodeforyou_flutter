# PlaceHolderWidget

A single, dependency-free Flutter widget that renders a centered
"under construction" placeholder image. Drop it into any slot in a layout
that is not built yet, or use it as the visual fallback while real content
is still loading.

![PlaceHolderWidget rendered at 800×600](test/golden/goldens/place_holder_widget.png)

## Features

- `PlaceHolderWidget` — a `const`, stateless widget with no required
  parameters.
- Centers the bundled `assets/placeholder512x512.png` inside its parent
  using `BoxFit.contain`, so it scales down cleanly into any box.
- Decodes the image at a fixed 256×256 physical pixels (`cacheWidth` /
  `cacheHeight`) to keep the in-memory footprint small regardless of the
  size it is drawn at.
- Depends only on `flutter/widgets.dart` — no Material or Cupertino
  requirement, so it works in any widget tree.
- Asset access goes through a generated `Assets` class (`flutter_gen`),
  so the asset path is type-checked rather than a string literal.

## Getting started

This package lives in the `icodeforyou_flutter` monorepo and is resolved
through the pub workspace (`resolution: workspace`). Add it to the
consuming package's `pubspec.yaml`:

```yaml
dependencies:
  place_holder_widget: ^1.0.0
```

Then bootstrap from the monorepo root:

```sh
melos bootstrap
```

No asset registration is required in the consuming app — the placeholder
image is bundled by this package.

## Usage

Import the barrel and place the widget wherever a view is still to come:

```dart
import 'package:flutter/material.dart';
import 'package:place_holder_widget/place_holder_widget.dart';

class SettingsScreen extends StatelessWidget {
  const SettingsScreen({super.key});

  @override
  Widget build(BuildContext context) {
    return const Scaffold(
      body: PlaceHolderWidget(),
    );
  }
}
```

The widget fills whatever constraints it is given and centers the image
inside them, so it can be used as a full-screen body, a tab page, or a
small card child without any extra sizing.

## Additional information

### Testing

Behaviour tests live in `test/src/` and feed the 100% LCOV gate. Run them
from the package root:

```sh
fvm flutter test --exclude-tags golden --coverage
```

### Goldens

The PNG above is produced by the golden test in `test/golden/`. Goldens are
tagged `golden` and excluded from the normal run (see `dart_test.yaml`)
because rasterisation is not byte-identical across platforms. Regenerate
locally on macOS after any visual change:

```sh
melos exec --scope="place_holder_widget" -- fvm flutter test --update-goldens --tags golden
```

See `test/golden/GOLDEN.md` for the full procedure.

### Regenerating the asset class

`lib/gen/assets.gen.dart` is generated by `flutter_gen_runner`. After adding
or renaming anything under `assets/`, rerun:

```sh
fvm dart run build_runner build
```

### Contributing and issues

This is a private workspace package (`publish_to: none`). Changes follow
the monorepo conventions: `icodeforyou_lints` for analysis, one widget per
file under `lib/src/`, and a matching `_test.dart` under `test/src/`.
